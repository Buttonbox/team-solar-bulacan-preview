# Team Solar Bulacan — client website preview

Static, sample-only visual preview. This folder excludes the Node backend, admin dashboard, inquiry database, credentials, and private configuration. The quotation form does not save or send data. Images are illustrative generated visuals; project sources are linked on the page.

To publish with GitHub Pages: place these files at the root of a separate preview repository, then choose Settings > Pages > Deploy from a branch > main > /(root). Use the exact URL GitHub shows after deployment succeeds. Publishing makes the preview available online and requires owner authorization.
